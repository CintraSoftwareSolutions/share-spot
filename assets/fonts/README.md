Active bundled app font:

- General Sans variable font: app-wide typography and branded headings

General Sans is distributed under the Fontshare/Indian Type Foundry Free Font
License. The included license is stored in `FFL-GeneralSans.txt`.

Montserrat and Playpen Sans Hebrew source files are retained as unbundled
alternatives. To switch later, update `pubspec.yaml` and the aliases in
`lib/core/constants/app_fonts.dart`.
